Sobre o projeto:
Este site foi desenvolvido como um projeto de estudo, no qual utilizei um site como referência e modelo para recriar sua estrutura e aplicar meus conhecimentos de HTML e CSS. Como ainda sou iniciante em desenvolvimento web, o objetivo foi praticar a organização de elementos, estilização, alinhamento e responsividade, buscando reproduzir a proposta visual do site de referência e, ao mesmo tempo, aprender com o processo.
